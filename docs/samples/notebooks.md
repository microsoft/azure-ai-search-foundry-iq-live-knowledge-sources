# Notebooks

The notebooks provide guided walkthroughs for people who prefer an executable tutorial.

Use:

```text
notebooks/01-mcp-server-ks-quickstart.ipynb
notebooks/02-fabric-ontology-ks-airline-ops.ipynb
```

The MCP notebook builds the MCP Knowledge Source payload, creates the MCP-only Knowledge Base payload, optionally performs live retrieve, and inspects an offline MCP trace.

The Fabric notebook validates Airline Ops sample facts, reviews the ontology contract, builds Fabric Knowledge Source and combined Knowledge Base payloads, optionally performs delegated live retrieve, and inspects offline Fabric traces.

Next: use [MCP Server KS](../03-mcp-server-ks.md) or [Fabric Ontology KS](../04-fabric-ontology-ks.md).
