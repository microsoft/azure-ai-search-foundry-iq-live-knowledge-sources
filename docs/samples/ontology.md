# Airline Ops Ontology

The Airline Ops sample gives the Fabric Ontology path a concrete business shape without using customer data.

Use:

```text
samples/data/airline-ops/
samples/ontology/airline-ops/ontology-contract.yaml
samples/ontology/airline-ops/ontology-map.svg
```

The sample covers carriers, airports, routes, flights, delay events, passenger-care policies, and regulatory-style references. The rows are tiny, synthetic, and tutorial-focused.

Use this area when you want to:

- understand the entities and relationships used by the Fabric path,
- map sample facts into an existing Fabric ontology,
- check expected validation questions before creating a Fabric Ontology Knowledge Source.
